<!-- ABOUT THE PROJECT -->
## Sobre o projeto 💡

Aplicação desktop feita em Python com PyQt6 para organização de cartas de Pokémon TCG em formato de fichário.

O sistema permite:

- Criar fichários personalizados 
- Adicionar, editar e remover cartas  
- Visualizar cartas em formato de grade (3x3)  
- Alternar entre diferentes fichários  

A interface simula um fichário real, com separação entre abas e páginas de cartas.

## Como iniciar ▶️

### Instalação 📦

1. Acesse a página de releases:
   https://github.com/DiAngello/catalogo-pokemon-tcg-python/releases

2. Baixe o arquivo `.zip` mais recente

3. Abra o terminal na pasta onde você extraiu e dê permissão de execução ao binário:
   ```sh
   chmod +x app
   ```
4. Execute o aplicativo:
     ```sh
   ./app
   ```

## Uso 📌

1. Crie um novo fichário ou selecione um existente
    
2. Clique em **"Adicionar carta"**  

3. Escolha:
   - AUTO → salvar na coleção oficial  
   - Fichário personalizado  

4. Comece a organizar suas cartas
